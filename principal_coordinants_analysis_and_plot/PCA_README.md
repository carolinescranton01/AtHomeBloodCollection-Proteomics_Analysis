# Principal coordinants analysis and plot

This code was used to conduct a PCA analysis in R. Analysis was conducted on the entire dataset (entire proteome of all 32 samples) and on a subset of samples 
(the immediately-processed samples per each participant - three capillary-collected samples, used to establish a baseline proteome, and one venous sample). 

Statistical analysis via PERMANOVA test was done to determine whether samples clustered significantly by different variables, such as participant or collection
type. 

PCA analysis was plotted using ggplot2
