# AtHomeBloodCollection-Proteomics_Analysis
R code used to analyze proteomics data (in RFU) from blood collected using at-home blood collection kits, and subjected to different temperature and time parameters pre-processing

Analysis was conducted in R studio (2024.04.0+735, R version 4.3.1) and in Microsoft Excel V16.96.1

Code will be organized in folders for each type of analysis, with README.md files in each folder containing info on input files and steps in the code, and R scripts with generic names for variables which will be specified in the code (ie. ~/path/to/data/data.xlsx).
